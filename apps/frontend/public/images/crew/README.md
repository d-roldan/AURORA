# Retratos de la tripulación ficticia

Generados con ImageGen el 15/11/2026 para esta demo. No son fotografías de astronautas reales ni representan personas reales identificadas. Se mantienen en el propio frontend, sin URLs de terceros ni servicios externos en ejecución.

- crew-01.png → Lucas Orozco, código estable CREW-01.
- crew-02.png → Elba Quaife, código estable CREW-02.
- crew-03.png → Fausto Villalba, código estable CREW-03.
- crew-04.png → Gabriela Iglesias, código estable CREW-04.

La asociación utiliza el código estable del seed, nunca el UUID regenerable, el orden ni el nombre editable. Perfiles nuevos y fallos de carga muestran icono e iniciales con nombre accesible. El nombre y código visibles continúan como identificación autoritativa; la imagen es una ayuda visual sintética.
