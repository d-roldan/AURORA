# AURORA V0.1.1

15/11/2026 · Actualización de identidad visual y navegación sobre V0.1.0.

- Logo AURORA suministrado por el usuario en la barra lateral y como favicon local. Se conserva el JPEG original.
- Control de misión muestra un encabezado simplificado; la misión permanece en la barra superior.
- Control para expandir/contraer la barra ubicado junto a la misión en la cabecera.
- Menú reducido a Control de misión, Tripulación, Telemetría, Eventos y Configuración. Sistema y Simulador conservan sus rutas directas y autorización de backend.
- Versión 0.1.1 sincronizada en manifiestos, lockfiles, imágenes Compose, UI y metadatos de API.

Validación de entrega: Compose válido; imágenes frontend, backend, analytics y simulator construidas. TypeScript/Vite y TypeScript/NestJS compilan. Diez pruebas de gráficos/continuidad/sesión, diez de backend y cinco de analítica aprobadas (25 en total). Las inspecciones de navegador de los cambios de presentación están documentadas en VALIDATION.md.

Límites: persiste el aviso del bundle JS mayor a 500 kB y 16 advertencias de deprecación en la suite Python. No se reejecutó el recorrido completo crew-navigation ni los escenarios integrales de telemetría para esta entrega. No hay cambios de esquema ni migraciones nuevas. La entrega publica código y fuentes en GitHub; no publica imágenes Docker en un registro ni despliega un sitio público. Datos de demostración exclusivamente sintéticos; no es un dispositivo médico validado.
